# 📦 Inventra - Voorraadbeheer App

> Een moderne, gebruiksvriendelijke voorraadbeheersysteem voor het efficiënt beheren van inventaris in uw bedrijf.

## 🎯 Over Inventra

**Inventra** is een geavanceerde voorraadbeheer-applicatie die bedrijven helpt hun inventaris effectief te beheren. Met een intuïtief design en krachtige functies kunt u uw voorraden real-time volgen, beheren en optimaliseren.

De app is gebouwd met moderne technologieën (TypeScript, JavaScript) en Expo, waardoor het beschikbaar is op meerdere platforms.

## ✨ Hoofdfuncties

- 📊 **Real-time voorraadbewaking**: Volg uw inventaris in real-time
- 🔍 **Geavanceerd zoeken**: Snel items vinden in uw voorraad
- ➕ **Voorraadbeheer**: Gemakkelijk items toevoegen, wijzigen en verwijderen
- 📈 **Rapportage**: Inzichten in uw voorraadbewegingen
- 📱 **Cross-platform**: Werkt op iOS, Android en web
- 🔐 **Veilig**: Beveiliging van uw gevoelige voorraadinformatie
- ⚡ **Snel**: Optimale prestaties en gebruikerservaring

## 🚀 Aan de slag

### Vereisten

- **Node.js** (versie 16 of hoger)
- **npm** of **yarn** package manager
- **Expo CLI** (optioneel, maar aanbevolen)

### Installatie

1. **Clone het repository**
   ```bash
   git clone https://github.com/0milan0/Inventra.git
   cd Inventra
   ```

2. **Installeer dependencies**
   ```bash
   npm install
   ```

3. **Start de ontwikkelings-server**
   ```bash
   npx expo start
   ```

4. **Open in je voorkeurzplatform**
   - Druk op `i` voor iOS simulator
   - Druk op `a` voor Android emulator
   - Druk op `w` voor web browser
   - Scan de QR-code met Expo Go app
